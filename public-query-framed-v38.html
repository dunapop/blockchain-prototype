前端查询端业务流程图

前端查询端只负责公开查询和详情核验，不产生新增、上传、提交或修改数据。当前查询结果列表不展示登记状态，只展示作品、创作者、存证编号、登记编号和操作。

一、身份证查询流程

输入身份信息用户输入姓名、身份证号。
→
查询本人作品系统按证件号检索名下版权作品。
→
展示结果列表列表展示作品名称、作品类别、创作者、存证编号、登记编号和操作。
→
查看详情根据记录是否有登记编号，进入登记详情或存证详情。

二、证书 / 存证查询流程

输入编号输入登记证书号、存证编号或链上地址。
→
匹配记录系统匹配登记记录和区块链存证记录。
→
返回结果如果命中登记编号，返回登记详情；如果命中存证编号，返回存证详情。
→
核验信息可核验登记编号、存证编号、TxHash、区块高度和存证时间。

三、查询结果列表字段

字段说明
作品名称 / 作品类别 / 创作者展示作品基础信息。
存证编号有区块链存证时显示；无存证时显示“—”。
登记编号有版权登记时显示；无登记时显示“—”。
操作点击“查看详情”，系统按记录数据打开对应详情弹窗。

四、详情弹窗规则

详情页面触发条件展示内容
查看登记弹窗记录存在登记编号作品基础信息、著作权人信息、权利拥有状况、登记编号、登记日期、登记机构和证书信息。
查看存证弹窗记录无登记编号但存在存证编号作品基础信息、存证编号、链平台、TxHash、区块高度、文件 Hash 和存证时间。
