一、区块链存证业务线

→

二、版权登记业务线

新增登记 / 上传Excel录入单条数据或批量导入登记数据。
→
待上传资料等待上传权利保证书、证件、其他材料。
→
待提交材料齐全后提交登记申请。
→
已提交 / 办理中登记机构受理审核。
→
已登记并存证 / 已驳回发证并完成存证，或退回修改后重新提交。
